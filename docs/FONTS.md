# Строки, шрифты и эмодзи

UTF-8 в исходнике не гарантирует, что графическое окно сможет нарисовать текст.
Строковые операции, сегментация текста и растеризация шрифта — разные возможности.

| Уровень | Что поддерживается | Ограничения |
|---|---|---|
| Строка UTF-8 | Кириллица, эмодзи, `\u{1F98A}`, JSON | `size` считает байты, `str_length` — кодовые точки |
| Графемы Unicode 16 | UAX #29: combining marks, skin tones, ZWJ, флаги, Hangul, Indic conjuncts | Это сегментация текста, а не shaping или измерение изображения |
| Встроенный шрифт | Латиница, кириллица, цифры и фиксированные символы | Неизвестный символ рисуется как `?`; масштаб целый 1..32 |
| TTF/OTF | Монохромные сглаженные Unicode-глифы, 8..96 px, fallback между faces | Нет shaping, kerning, bidi, COLR/CPAL, CBDT/sbix; bitmap-only emoji fonts отклоняются |
| PNG-атлас | Цветные изображения любых иконок | Подбор значка и лицензия атласа остаются у приложения |

## Байты, кодовые точки и графемы

| Строка | byte_size / size | char_length / str_length | grapheme_length |
|---|---:|---:|---:|
| 🦊 | 4 | 1 | 1 |
| 👨‍👩‍👧‍👦 | 25 | 7 | 1 |
| 🇷🇺 | 8 | 2 | 1 |
| e + U+0301 | 3 | 2 | 1 |

<!-- skrumi-run -->
```cpp
string family = "👨‍👩‍👧‍👦";
assert_equal(byte_size(family), 25);
assert_equal(char_length(family), 7);
assert_equal(grapheme_length(family), 1);
assert_equal(grapheme_substring(family, 0, 1), family);
assert_equal(grapheme_split("🦊🇷🇺"), ["🦊", "🇷🇺"]);
```

`grapheme_substring(text,start[,length])` отклоняет отрицательные индексы,
обрезает выход за конец и возвращает пустую строку для start за концом.
Все графемные API отклоняют повреждённый UTF-8 с указанием смещения байта.
Существующие `str_*` сохраняют прежнюю семантику кодовых точек.

Поля `ui_text` / `ui_text_field` используют графемы для Backspace, Delete,
стрелок, клика и прокрутки. Вставка пересегментирует строку: модификатор,
пришедший отдельным событием ОС, объединяется с предыдущим символом.
Ctrl+A/C/X/V сохраняют составные последовательности. Наличие графемного
редактирования не добавляет отсутствующие глифы выбранному шрифту.

## Встроенный набор

5×7, с выносными элементами в ячейке высотой 9 пикселей:

- A–Z, a–z, А–Я, а–я, Ё/ё, 0–9, пробел.
- ASCII-пунктуация: `. , : ; ! ? - + / = ( ) [ ] _ " ' \` % * # < > @ & { } | $ ^ ~ \\`.
- `♥ ❤ • ★ ⚡ ☠ ← → ↑ ↓ ⬆ ⬇ ° № « » — – × …`.
- `\n` переводит строку. Неизвестные кодовые точки заменяются `?`.

`draw_text` с текстом `🦊 • ★` теперь рисует `?`, точку и звезду.
`❤️` содержит variation selector и не становится цветным сердцем.
Для монохромного сердца используйте одиночные `♥` или `❤`.

<!-- skrumi-run -->
```cpp
using graphics;
assert(text_supported(0, "Лис • ★ ❤"));
assert(!text_supported(0, "🦊"));
assert_equal(text_missing_glyphs(0, "🦊🦊"), ["🦊"]);
```

`text_supported(font,text)` и `text_missing_glyphs(font,text)` не требуют окна;
0 обозначает встроенный шрифт. Для TTF проверяется наличие глифа в цепочке
fallback. Составные графемы без shaping консервативно считаются неподдержанными,
даже если все отдельные кодовые точки есть в шрифте. Это проверка надёжного
отображения, а не обещание корректного complex-script layout.

## TTF и fallback

Загрузите файл `load_font_file(path)` или байты `load_font(bytes)`.
`font_with_fallback(body,fallback)` создаёт новый handle. Цепочки объединяются,
повторные faces удаляются, максимум — 32 разных faces. `free_font` исходного
handle не ломает уже созданную цепочку. Сама цепочка освобождается своим handle.
`font_text_width` и `draw_font_text` выбирают один и тот же face для каждого
символа и используют его advance. Базовая линия задаётся основным шрифтом.

Fallback не загружает системные шрифты автоматически и не добавляет цветной
рендер. Крупные emoji-шрифты могут превышать лимит 8 МиБ. Для цветных игровых
иконок используйте свой PNG-атлас с разрешённой лицензией, `load_image`,
`draw_image_part`, `draw_sprites`. Для UI без ресурсов удобнее встроенные символы.

| Возможность | Windows | Linux/X11 | Android | Web |
|---|---|---|---|---|
| UTF-8 и графемы | Да | Да | Да | Да |
| Встроенный шрифт | Да | Да | Да | Да |
| TTF/OTF из байтов | Да | Да | Да | Да |
| Fallback faces | Да | Да | Да | Да |
| Цветной emoji/shaping/bidi | Нет | Нет | Нет | Нет |
| PNG-иконки | Да | Да | Да | Да |

Нативный тест `unit_unicode` выполняет официальный GraphemeBreakTest Unicode 16;
`unit_font` проверяет метрики и растеризацию. Матрица описывает реализацию;
результаты проверок конкретной сборки смотрите в CI.
