# Звук и микшер

`using sound;` предоставляет два API. `play_sound`/`play_tone` сохраняют
совместимость и возвращают bool. Новый `play_sound_ex(path,channel,volume,loop)`
возвращает handle, а ошибки устройства/декодирования сообщает исключением.
Именованных аргументов нет: параметры передаются по порядку.

| Возможность | Windows | Linux, обычная сборка | Linux, static musl | Android | Web |
|---|---|---|---|---|---|
| Старый play_sound | Встроенный микшер | Внешний проигрыватель | Внешний проигрыватель | MediaPlayer | Нет |
| play_sound_ex | miniaudio | miniaudio, системный audio backend | Требует backend; dlopen недоступен в static musl | miniaudio, backend устройства | Явная Audio Error |
| Форматы нового API | WAV/MP3/FLAC/Vorbis | Те же | Декодер есть; устройство может быть недоступно | Те же | Нет |
| Каналы/громкость/loop/pause/pan/fade | Да | Да | Только при доступном устройстве | Да | Нет |

Портативный static musl executable не может динамически загрузить системные
ALSA/PulseAudio библиотеки. Для нового микшера на Linux используйте обычную
CMake-сборку; старый API по-прежнему работает через внешний проигрыватель.
Микшер не подменяет отсутствующее аудиоустройство молчаливым null-backend.
Наличие backend и фактическую задержку нужно проверять на целевом устройстве.

Новый микшер смешивает до 128 звуков, декодирует музыку потоком и работает
на 48 кГц stereo. Каналы: SFX=0, MUSIC=1, UI=2. Громкости 0..1 перемножаются:
громкость звука × канала × master. Панорама -1..1, 0 — центр.

```cpp
using sound;
try {
    set_master_volume(0.7);
    set_channel_volume(SFX, 0.9);
    int music = play_sound_ex("music/forest.ogg", MUSIC, 0.5, true);
    int hit = play_sound_ex("sounds/hit.wav", SFX, 0.8, false);
    set_sound_pan(hit, -0.3);
    pause_sound(music);
    resume_sound(music);
    fade_out(music, 1000);
} catch (error) {
    print("Звук недоступен: " + error);
}
```

Handle действует, пока звук хранится микшером; завершённые звуки освобождаются
при следующем запуске. `sound_playing(handle)` возвращает false для завершённого
или удалённого handle. `stop_sound` идемпотентен, остальные изменения несуществующего
handle — ошибка. `stop_sounds` прекращает оба API. Перезапуск проигравшего
звука делается новым play_sound_ex. Pause/resume сохраняет позицию, loop — без
ручного повторного открытия файла. Fade рассчитывается на аудиопотоке.

Для старого Linux API очередь можно держать в игре: добавлять пути в массив,
запускать следующий по таймеру с известной длительностью. Она предотвращает
наложение, но не заменяет микшер; точность зависит от внешнего проигрывателя.

`unit_audio` проверяет сумму PCM двух голосов, паузу, канальную громкость и
затухание в offline-engine без звуковой карты. Это проверка математики микшера,
а не измерение задержки реального оборудования.
