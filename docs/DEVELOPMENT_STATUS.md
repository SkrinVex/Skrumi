# Статус предложений из игрового опыта

Этот файл отделяет реализованные изменения от направлений, которым нужен
отдельный дизайн. Список не означает, что каждое предложение исходной заметки
уже реализовано. Подробные контракты находятся в справочнике и отдельных руководствах.

Текущая задача — согласовать документацию, сайт и конструктор с опубликованным
языком, без новых возможностей runtime. Пакетный менеджер и геймпад исключены
из ближайших работ по решению автора проекта. Остальное ниже — предложения
на будущее, а не обещания текущего релиза.

| Направление | Реализовано | Что остаётся |
|---|---|---|
| Синтаксис | Ленивый ?:, постфиксные поля/элементы, битовые операции и присваивания, hex/binary/exponent/underscore, /* */, BOM | prefix ++/--, do/while, метки, switch expression |
| Типы | Проверки известных типов ветвей/операндов, сохранение typed-container ограничений | Полное выведение общих типов динамических выражений, int64/uint64, frozen, flow narrowing, is/as |

Некоторые пункты уже существовали до обновления: `get_or` для безопасного чтения,
`obj?.method()`, глубокая `copy`, aliases модулей. Они документированы, а не
представлены как новые возможности.

Измерение шрифта учитывает fallback и advances, но не shaping. Проверка
text_supported консервативно отклоняет составные графемы, поэтому её нельзя
использовать как доказательство отсутствия отдельных глифов.

## Оставшиеся предложения для следующей заметки

Ниже только то, чего ещё нет. Приоритеты нужно выбрать отдельно; отсутствие
этих возможностей не мешает установке и использованию текущего релиза.

### Удобство языка

- Именованные аргументы и значения параметров по умолчанию.
- `??=`, безопасная индексация, сужение nullable-типа после проверки,
  операторы проверки/приведения `is` и `as`.
- Префиксные `++`/`--`, `do/while`, метки `break`/`continue`,
  `switch`-выражение и явный `fallthrough`; сопоставление с образцом — отдельно.
- Полноценные `int64`/`uint64` и глубокая неизменяемость `readonly`/`frozen`.
  `clock_ms64()` пока использует float, это не 64-битный целый тип языка.
- Полное выведение общего типа ветвей с динамическими значениями.
- Прямой квалифицированный доступ к встроенным именам вроде `std.size`;
  aliases пользовательских модулей уже есть.

### Диагностика и редактор

- Предупреждения unused/unreachable/fallthrough, о подозрительном `size(string)`,
  разделяемых структурах и пустом `catch`; отключение отдельных кодов в манифесте.
- Более полное восстановление после синтаксических ошибок и единый каталог
  кодов со ссылками на объяснения.
- Стек вызовов, колонки и локальные значения в обычном текстовом runtime-отчёте.
- Inlay hints, semantic tokens, quick fix пропущенной `;` и настройки форматтера.

### Инструменты и библиотека

- `watch` (проверка/перезапуск после сохранения), REPL, горячая перезагрузка.
- Параметризованные тесты, fixture hooks (`before_all`/`after_all`), coverage.
- `array_binary_search`, независимые объекты Random, camera shake и дополнительные easing.
- Генерация полного индекса API, HTML-справочник с поиском и полный английский перевод.
  Английский обзор, русские руководства и выполняемые примеры уже есть.

### Текст, графика, звук и ввод

- Shaping, kerning, bidi, системный fallback и цветные форматы шрифтов
  COLR/CPAL/CBDT/sbix. Альтернатива для игр — готовый лицензированный emoji-атлас
  с сопоставлением графем и иконок; ручной PNG-атлас уже поддерживается.
- Полноценный IME, произвольное выделение диапазона текста и правила переноса
  для сложных письменностей. Текущее редактирование и перенос сохраняют графемы.
- RGBA render targets, additive blend, дуги/Bezier, иконка окна. Vsync/GPU —
  отдельное направление; ограничитель FPS уже реализован.
- Web audio, backend устройства для static-musl сборки, дополнительные формы
  тона и огибающие attack/decay/release, измерение задержки на реальных устройствах.
- Multitouch, переназначение действий через input map, pointer lock в браузере.

Геймпад и пакетный менеджер сейчас не планируются. Перегрузки, смена ссылочной
семантики структур и смена fallthrough по умолчанию также не являются задачами:
в исходной заметке они не требовались либо прямо предлагалось сохранить поведение.

## Проверки

- Официальный GraphemeBreakTest Unicode 16: 1093 случая.
- Offline PCM mixer: сумма двух голосов, mute/pause/resume/fade.
- Pixel tests: alpha, clipping, rotation/flip, PNG roundtrip, canvas lifetime.
- Native window: limiter, курсор/захват при доступном фокусе, графемное удаление
  и последовательные combining events.
- CLI: init без перезаписи, проектная сборка/force с защитой исходника, BOM,
  malformed literals, parser recovery, warning exit policy, fmt idempotence.
- LSP: quick fix затенённого параметра изменяет объявление и его ссылки.

Локальные проверки выполнены на Linux/X11. Реальные Windows/Android устройства,
цветные шрифты и аппаратная задержка аудио требуют отдельных измерений;
платформенные сборки проверяются CI. Файл moon_forest.skm не был предоставлен
и в репозитории отсутствует, поэтому проверка именно этой игры не заявляется.
